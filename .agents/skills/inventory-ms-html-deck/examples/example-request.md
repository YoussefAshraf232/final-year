# Example invocation

```text
/inventory-ms-html-deck create presentation/index.html
```

Then provide:

- official project title;
- student names;
- supervisor names;
- university and department;
- target presentation duration;
- preferred language;
- any additional screenshots;
- whether a live demo will be included.

Example natural-language request:

> Build the final HTML defense deck for this repository. Match the existing Inventory MS interface, use the current code and migrations as the source of truth, include a 12-minute speaking flow and appendix, then use Playwright to inspect every slide at 1920×1080 and 1366×768. Do not report completion until the QA report passes.
